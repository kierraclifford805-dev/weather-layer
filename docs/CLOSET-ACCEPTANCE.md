# 我的衣橱与分时穿搭验收

日期：2026-10-24。改动仅保存在本地，未提交、推送或发布。继续使用原生 HTML/CSS/JS 与 GitHub Pages `/weather-layer/`，未新增依赖。

## 实现与入口

穿搭区域的「我的衣橱」可导入照片；首次进入或天气失败时也可从「先整理我的衣橱」进入。照片在本机处理与保存，由用户确认类型、厚薄及名称。首版按原有穿衣规则匹配这些标注，没有调用 AI 图像服务。

天气推荐同时支持全天（07–21）、早间（07–09）、白天（11–16）、晚间（18–21）。时间均为查询城市当地时间；默认全天最低体感与原有规则一致。城市或日期变化重置时段，体感偏好变化保留所选时段；全天温差与随身建议不会被局部时段替换。

已拥有单品展示照片和名称，并标注「我的衣橱」。缺少合适单品时显示插画及「建议单品 · 衣橱暂缺」。有合适的同类备选才允许换一套；备选不足给出说明。没有体感数据不会生成自有衣物穿搭。

## 自动测试

运行：`node --test tests/*.test.js`（本机 Node 24 运行时）。**130 项通过，0 失败。**

本轮新增检查包含：

- 自有衣物优先；缺失单品不伪装成拥有；类型／厚薄不符时不强行凑齐。
- 当日稳定候选、换一套、已移除衣物排除；不改动原有温度阈值。
- Blob 照片读回、编辑、移除、恢复、永久删除；并发导入的 100 件上限与恢复容量限制。
- 不支持格式、超过 12 MB、无效元数据、不可用存储的错误处理。
- 自有衣物照片进入 DOM、刷新后保留；名称转义，编辑／恢复即时更新推荐。
- 时段最低体感与 07–21 边界、非目标日不混入；有效 0 与缺失／无效值区分。
- 切换城市／日期／个人体感、保留温差和七天预报；缺失日期明确说明。

完整回归也包含原有 UV 分档、日期跨年／夏令时、提醒权限、身份校验、任务并发去重、过期和推送服务状态等单元与集成测试。没有据此声称真实设备收到通知；本轮未重新运行 Workers 部署或 workerd 验收。

## 实际浏览器检查

使用应用内浏览器实际渲染。375、390、768、1440px 均分别读取 `innerWidth` 确认生效，页面 `scrollWidth` 与宽度一致，没有页面横向溢出。200% 字号下衣物展示会自动减少列数。

- 从本地文件选择器实际导入 3 张测试 JPEG，逐件保存为针织衫、保暖厚外套、长裤；不是仅插入演示 DOM。
- 刷新、关闭测试页后重新打开，3 张照片仍由 IndexedDB 读回；推荐中的 Blob 图片全部实际加载。
- 实际点击移除长裤，衣物数与推荐同步减少；从最近移除恢复后重新进入穿搭。
- 手机与桌面衣橱弹层、浅色／深色、时段切换、今天／明天、长城市名、200% 字号、部分数据缺失、请求失败、提醒设置面板均已检查。
- Escape 关闭衣橱后，焦点返回入口，背景滚动锁定解除。分时段键盘操作另有 DOM 集成测试。
- 正常 `/weather-layer/` 实际请求天气；检查时读取到北京 2026-10-24 的天气，页面没有开发模拟标签或衣橱测试照片。
- 衣橱测试在独立 `8766` 开发预览来源进行，测试图片均命名为「测试·…」。没有向正常 `8765` 来源加入假衣物，没有发送照片到后端。

测试 JPEG 来自本项目原创衣物 SVG 的浏览器截图；仅用于验收，不代表用户上传的真实衣物。天气预览始终带「仅开发预览 · 模拟数据」标签。

## 功能边界、隐私与上线

- **真实可用**：本机照片导入、分类、存储、编辑、恢复／删除，以及按天气挑选现有衣物。无需额外账号、密钥、数据库或付费服务。
- **尚未实现**：AI 识图／自动抠图、色彩和场合造型、账号登录／跨设备云同步、裙装／连衣裙／鞋类专门规则。本轮不声称这些能力。
- 衣橱只保存在当前来源的当前浏览器，不上传到天气数据源或 Cloudflare。重编码不保留原图 EXIF；原始照片需自行备份。
- 明日提醒仍是原有通用天气简报，不读取本机衣橱；`API_BASE` 仍为空，没有伪造已开启、发送或送达状态。
- 真实 iPhone／iPad／Android、Safari、系统相册 HEIC、浏览器重启／系统回收存储、原生存储额度耗尽和真实 Web Push 设备送达未实测。配额与存储错误逻辑有自动化覆盖；实际照片链路仅实测 JPEG。
- 上线仍沿用静态部署，需由用户决定发布。本轮没有提交、推送或发布。未来云同步／AI 服务需要另行确定上传范围、账号与服务端密钥方案。
- 回退前端版本不会主动删除 `weather-layer-closet-v1`。不要用清空浏览器数据作为回退步骤；再次使用当前版本可读取仍保留的本机衣橱。变更网站来源后需要重新导入。
