# 添一件 · 视觉深化与验收 · 2026-10-28

原页面的衣物轮廓、空衣橱和同级卡片较为单薄，桌面穿搭较长时右侧留下大片空白。本轮围绕用户“画面过于简单”的反馈，增加织物与生活场景、编辑式排版，以及更完整的主辅信息布局。基于 `7a28d37` 增量修改，仍是无需构建的静态应用。

## 画面变化

- 首页天气窗增加静态光线层次与衬线主标题；防晒采用克制的暖色光晕，今晚准备单增加月夜图形。天气结论、场景、日期及 UV 数据仍由原数据驱动。
- 每日穿搭采用“穿搭手札”排版：日期签、章节编号、米白纸面、蓝／暖白／鼠尾草绿的平铺区域，以及单品说明。保留真实照片、单件替换、撤销和搭配记忆。
- 增加实际衣橱匹配摘要，按有效自有穿着单品计算，例如 `2 / 3 件来自我的衣橱`；随身用品不计入该数字。没有体感数据时隐藏，不能把缺失数据画成完成状态。
- 14 种衣物／用品使用同一套重新绘制的 SVG：柔和织纹、缝线、纽扣、口袋、折痕与阴影。原轮廓文件保留，统一在 `visuals.js` 切换到 `assets/clothes/studio/`，天气温度阈值没有变更。
- 衣橱加入原创生成的衣架场景，明确标注“衣橱场景插画”，不生成用户衣物记录。空衣橱先显示场景与三步引导；有衣物时显示真实数量和图形分类。筛选时收起场景，保留搜索与分类。
- 桌面 1100px 以上：左侧天气／穿搭为主，右侧防晒、提醒、趋势、七天预报连续排列；浏览器实测提醒与趋势间距为 24px。手机仍按原信息顺序单列。
- 深色主题使用独立纸面与衣物背景变量；200% 字号时，衣橱场景自动改为文字在上、插画在下，避免将文字挤成窄列。保留可见键盘焦点与减少动态效果支持。

## 文件

- `editorial.css`：新增独立视觉层；`styles.css`：集中增加浅／深色纸面、辅助颜色与本地衬线字体变量。
- `index.html`：手札标题、匹配摘要、衣橱场景及分类区结构。
- `visuals.js`：统一衣物素材路径、场景素材和五种分类图形。
- `closet.js`：真实库存对应的场景／空状态、图形分类、随身物品的编辑文案。
- `outfit-view.js`：匹配摘要，推荐与确认逻辑沿用原规则。
- `assets/clothes/studio/*.svg`：14 个自绘单品；`assets/editorial/wardrobe-scene.webp`：39,742 字节的场景图。
- `tests/visual.test.js`：新增 2 项数据真实性回归；`tests/visual-fixtures.js`：仅本机预览的示例图片使用新版 SVG。
- README 与本验收记录。其他相关前端及 shared 模块仅同步资源版本 `20261028-studio1`，避免混用旧缓存。
