# 衣橱与每日穿搭优化 · 2026-10-27

本轮在 `ca42a71` 的静态应用上增量修改；不改变原有穿衣温度阈值、身体数据对照方式或部署架构。GitHub 同步由用户本轮明确授权。

## 使用体验

- 衣橱先显示添加、搜索、分类和衣物，档案、格式说明、备份移至衣物后。搜索常显，分类显示件数；更多筛选仍支持厚薄及隐藏已知不合适的衣物。分类件数参考当前厚薄／合身筛选，不受搜索词影响，辅助标签有说明。
- 照片可通过点击或键盘进入编辑；独立“尺码／编辑”入口直达可选尺码信息。保存或返回后保留原分类、搜索、滚动位置，焦点返回相应衣物。
- 新的照片展示、卡片留白、统一操作位置和手机底部操作条。每日推荐在手机上采用两件主衣物与横向下装展示，档案入口移至穿搭后，先看要穿的衣服。
- 移除后可以立即撤销，也仍可在“最近移除”恢复。没有搜索结果时提供直接恢复全部衣物的入口。
- 多张导入显示当前张数与已保存／跳过数量；可跳过当前照片。某张格式不支持或解码失败后，剩余照片保留，通过“继续下一张”继续；结束添加只取消未保存部分。每张照片仍需用户确认类型和厚薄，不自动识图。
- 每个城市、当地日期、时段独立保留当前页面的临时换搭，最多最近 12 组。可撤销最近 10 步单件或整套换搭；选回当前衣物不会制造一次新调整。保存、恢复自动推荐或取消记住会清除该组撤销记录。
- 临时搭配只保存在内存，刷新不保留；明确点击“记住”才写入原本的本机搭配记录。天气／体感／身体档案变化或衣物失效后重新核对，不能通过草稿或撤销绕过天气及合身规则。

## 真实可用与边界

衣橱管理、照片处理、身体档案对照、天气搭配、单件选择、撤销及本机记忆均可实际使用。照片和身体资料仍不上传；同步 GitHub 的是网站代码，用户衣橱不会因推送代码而跨设备同步。

未新增 AI 识图、自动抠图、场合／色彩造型或推送服务。明日提醒后端仍未配置，设置及简报仅可预览。未在 iPhone／iPad、Android 实机、Safari、不同品牌尺码或真实设备通知上验证；本轮没有更改／部署 Workers。

## 回退

需要回退本轮时，在确认没有新改动后对本轮提交执行 `git revert <本轮提交>` 并推送。Pages 从 `main:/` 重建。数据结构没有升级，回退不会主动删除衣橱、档案或已记住的搭配；页面内未保存的临时调整会在刷新后消失。
