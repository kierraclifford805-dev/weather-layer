# 衣橱查找、备份与穿搭说明迭代

日期：2026-10-25。保留静态部署、原有城市／体感／日期规则与提醒功能，没有添加依赖，没有提交、推送或发布。

## 本轮完成

1. **查找衣物**：关键词、上衣／外套／下装／随身物品和厚薄可组合筛选；显示结果数，可一键清除，最近移除也能查找。手机默认收起筛选与保存说明，让照片优先出现。恢复或导入新衣物后清除旧筛选，避免新衣物被隐藏。
2. **说明搭配依据**：「这套怎么选的？」显示所选日期、时段最低体感、个人体感偏好，以及自有衣物的类型／厚薄匹配。缺项明确说明；没有体感数据时隐藏这类推断。原有温度阈值没有改变。
3. **本机备份与恢复**：下载 JSON，包含当前筛选的在用衣物及照片。仅在本机处理，备份不含最近移除、天气城市、体感偏好、提醒计划或凭证。每份 1–100 件、最多 64 MB；照片每张最多 2 MB。
4. **确认后合并**：先检验格式与图片是否可解码，再逐件列出新增／副本／重新启用／跳过计划。重复衣物不会继续叠加；同编号不同内容保留原件并加入副本。完全相同的最近移除衣物会重新启用。容量不足时禁止确认。
5. **失败与并发处理**：单次事务合并；中途失败回滚。其他标签页修改后旧预览失效，可重新检查。关闭检查界面后不会弹回陈旧结果；存储不可用时禁用写入、导出与恢复，天气工具继续可用。

备份格式采用显式版本号、照片类型／大小／文件头校验与本机 SHA-256 内容比较。SHA-256 用于比较照片，备份本身没有加密或签名，不应当作照片的保密存储。原始照片需要自行保留。

## 自动化检查

`node --test tests/*.test.js`：**150 项通过，0 失败**。使用项目既有的 Node 24 运行时与依赖。

本轮新增覆盖：

- 图片字节与元数据备份往返、筛选结果与最近移除的边界。
- JSON 版本、重复编号、无效分类、外部图片地址、SVG、非法 Base64、图片文件头与大小。
- 2 MB 图片编码边界、100 件容量；大文件先拒绝处理。
- 完全相同记录跳过、照片内容或名称变化形成副本、再次恢复不重复添加。
- 最近移除的相同衣物重新启用、原有衣物保留、恢复来源保留。
- 旧预览失效、并发恢复去重；第一条写入后主动中止事务，验证所有新增记录回滚。
- DOM 中的筛选、说明、确认前不写入、取消、失败、关闭后陈旧结果丢弃、存储不可用。

已有天气日期、夏令时、UV、提醒权限、安全校验、重试去重等回归也通过。本轮没有重新运行 Workers 部署／workerd 验收，没有测试真实推送送达。

## 实际浏览器验收

使用应用内浏览器，测试数据位于独立 `8766` 来源，页面始终标有「仅开发预览 · 模拟数据」。衣物图片和名称均为测试数据，没有写入正常 `8765` 来源。

- 组合筛选“外套 + 保暖 + 关键词”，实际得到 1 件；通过原生下载事件获得 JSON 文件，回读确认包含 1 件与 JPEG 照片，文件大小 23,533 字节。
- 通过原生文件选择器导入测试备份。确认前仍是原来 3 件；预览明确列出 2 件新增，其中 1 件编号冲突副本。确认后原 3 件保留，总数为 5。
- 重新导入同一文件，显示新增 0、跳过 2；确认后仍为 5 件。恢复完成后列表回到全部衣物，避免旧筛选隐藏恢复结果。
- 点击「换一套」实际改变了合适外套的选择。展开说明后，日期、07–21 时体感和真实衣物标注对应。
- 分别在 375、390、768、1440px 检查。读取 `innerWidth` 确认尺寸，检查页面与衣橱弹层没有横向溢出；截图保存在本记录旁。
- 实际检查深色衣橱、200% 字号下筛选自动单列、长城市名和缺失数据。缺失体感时不显示自有衣物推荐或搭配说明；天气请求失败时仍能进入衣橱并备份。
- Escape 关闭衣橱后焦点返回入口，背景滚动锁定解除；提醒面板继续明确标注服务端未配置。没有打开通知权限或发送测试通知。
- 已恢复正常 `8765` 入口：查询城市仍为北京，日期为 2026-10-25，没有开发预览标签，衣橱仍为 0 件。测试衣物与备份恢复仅发生在 `8766`，没有混入正常入口。

真实手机／iPad、Android、Safari 系统相册与下载位置、跨设备迁移、系统存储回收和真实配额耗尽未验证。格式错误、事务中断与存储不可用有自动化覆盖。实际备份图片链路使用 JPEG 测试衣物；没有重新测试 HEIC。

## 上线与保留范围

直接沿用既有静态托管方式，不需要新增账号、Secret 或后端服务。尚未接入自动识图、云同步或自有衣物推送；提醒仍使用通用天气穿衣建议，未配置的后端继续明确显示预览状态。

回退前可先下载衣橱备份。前端回退不应删除 IndexedDB，也不应以清空浏览器数据作为回退步骤。保持当前网站来源可继续读取本机衣橱；更换来源时通过文件恢复。备份含照片，迁移文件需要用户自行保管和传送。
