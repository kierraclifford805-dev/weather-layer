# 添一件 · 每日穿衣天气

根据当地气温、早晚体感和个人怕冷程度，给你一句实用的穿衣建议。

## 直接使用

**[打开添一件](https://kierraclifford805-dev.github.io/weather-layer/)**

无需登录，手机和电脑都可以使用。把上面的链接发给朋友即可。

1. 选择所在城市或搜索区县。
2. 查看当天气温、添衣建议和未来 7 天天气。
3. 按自己的情况选择「怕热 / 刚刚好 / 怕冷」。

## 功能

- 当前天气、最低／最高温与昨日最低温变化。
- 根据当地 07:00–21:00 最低体感给出内搭、外搭和下装建议。
- 早晚体感趋势、明显降温、大温差、降雨等出门提示。
- 记住当前浏览器的城市和体感偏好。
- 打开页面时更新天气；页面在前台时每 30 分钟检查更新和当地日期变化。

网页关闭后不运行，不发送定时通知。

## 部署与修改

这个仓库的 `index.html` 包含全部页面、样式和逻辑，无需构建或安装依赖。

GitHub Pages 的发布来源为 `main` 分支的根目录。修改 `index.html` 并提交后，GitHub 会自动更新公开页面。也可以将该文件放到其他静态网站托管服务。

穿衣规则在 `outfit()` 函数中：以白天最低体感为基础，怕冷时减 2°C、怕热时加 2°C 后选择衣物档位；显示的实际天气温度不变。规则只作日常穿搭参考，不是官方穿衣指数或现场实测。

## 数据与隐私

- 天气：[Open-Meteo](https://open-meteo.com/)；城市搜索：Open-Meteo Geocoding / GeoNames。
- 需要联网。默认开放接口用于个人非商业用途，其他用途请核对 [服务条款](https://open-meteo.com/en/terms)。
- 不获取设备定位。查询时把所选城市的坐标和城市搜索词发送给相应数据服务。
- 城市和怕冷程度只保存在当前浏览器，不在访客之间共享，不上传至 GitHub。
- 查询失败时显示错误信息，可点击「更新天气」或重新选择城市。
